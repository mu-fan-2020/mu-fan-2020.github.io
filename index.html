Hexo+Github搭建个人博客

Hexo

全局安装 Hexo 命令行工具

npm install: 这是 Node.js 包管理器 npm 的命令，用于安装软件包。
-g: 这是 npm install 命令的选项之一，表示全局安装软件包。
hexo-cli: 这是要安装的软件包的名称，即 Hexo 的命令行工具。

通过运行 npm install -g hexo-cli，你会将 Hexo 命令行工具安装到你的计算机的全局环境中，使得你可以在命令行中随时使用 hexo 命令来执行 Hexo 相关的操作，如创建新文章、生成静态文件等。

初始化 Hexo 博客项目

hexo init: 这是 Hexo 命令，用于初始化 Hexo 项目。
blog: 这是要创建的博客项目的名称。你可以根据需要选择任何名称。

通过运行 hexo init blog，Hexo 会在当前目录下创建一个名为 “blog” 的文件夹，并在该文件夹中生成 Hexo 博客项目的初始文件结构和配置文件。这些文件包括 _config.yml（配置文件）、source（存放源文件如 Markdown 文章）、themes（存放主题文件）等。

安装项目所需的依赖包

npm install: 这是 Node.js 包管理器 npm 的命令，用于安装项目所需的依赖包。

通过运行 npm install，npm 会查找当前目录下的 package.json 文件，并安装该文件中列出的所有依赖包。这些依赖包通常是项目所需的第三方库、工具或框架，它们包含了构建、运行和开发项目所需的代码和资源。

在执行 npm install 之前，请确保你已经在项目根目录下，并且已经有一个 package.json 文件，该文件中列出了项目的依赖项。安装完成后，npm 会在当前目录下的 node_modules 文件夹中创建一个或多个文件夹，用于存放所安装的依赖包。

清除 Hexo 生成的静态文件和缓存

hexo clean：这是 Hexo 命令，用于清除生成的静态文件和缓存。

通过运行 hexo clean，Hexo 将删除之前生成的静态文件和缓存，包括位于 public 文件夹中的所有文件。这个命令可以帮助你清理旧的生成文件，以便在之后执行 hexo generate 时重新生成最新的静态文件。

生成 Hexo 博客的静态文件

hexo generate：这是 Hexo 命令，用于生成静态文件。

通过运行 hexo generate，Hexo 将根据你的配置和源文件（如 Markdown 文章、主题模板等）生成静态 HTML、CSS 和其他资源文件。这些生成的文件将存储在 public 文件夹中。

生成静态文件是构建博客的重要步骤，它将源文件转换为可在 Web 浏览器中访问的静态页面。在生成过程中，Hexo 会执行一系列的转换、渲染和复制操作，将你的博客内容转换为可浏览的形式。

在执行 hexo generate 之后，你可以通过打开 public 文件夹中的 HTML 文件来查看生成的博客页面。这些文件可以上传到服务器进行部署，或者在本地使用 hexo server 命令启动本地服务器进行预览。

如果你对博客的源文件进行了修改或添加了新的文章，你需要重新执行 hexo generate 命令来生成更新后的静态文件，以确保最新的更改得到反映。

启动 Hexo 本地开发服务器

hexo server：这是 Hexo 命令，用于启动本地开发服务器。

通过运行 hexo server，Hexo 将在本地计算机上启动一个服务器，并监听指定的端口（默认为 4000）。这个服务器将使用生成的静态文件和配置来提供你的博客内容。你可以在浏览器中访问 http://localhost:4000（或指定的端口）来预览你的博客。

执行完上面的操作，你就可以在本地看到你的blog了。

Github

创建Github仓库

注册一个GitHub的仓库，然后在个人主页中选择 new 新建仓库。

注意： 仓库名称的前半部分与你的用户名一致，即 mu-fan-2020，后半部分 为 .git.io 固定格式，可以选择一个readme为说明文件（随便），然后点击创建仓库。

设置 Git 全局配置中的用户名和用户邮箱

username是你Github的用户名。
useremail是你申请Github的邮箱。

git config –global user.name “username” 是用于设置 Git 全局配置中的用户名的命令。它将用户名设置为 “username”。执行该命令后，你的 Git 操作将使用该用户名进行标识。

git config –global user.email “useremail” 是用于设置 Git 全局配置中的用户邮箱的命令。它将用户邮箱设置为 “useremail”。执行该命令后，你的 Git 操作将使用该邮箱进行标识。

生成 SSH 密钥对

ssh-keygen -t rsa -C “useremail” 是用于生成 SSH 密钥对的命令。它将生成一个 RSA 类型的 SSH 密钥，并与指定的邮箱关联。

通过运行 **ssh-keygen -t rsa -C “useremail”**，命令会提示你选择保存密钥文件的路径和文件名，并要求你输入一个可选的密码短语来保护密钥。一旦生成完成，将在指定的路径中创建两个文件：id_rsa（私钥）和 id_rsa.pub（公钥）。

一般密钥会生成在～/.ssh目录下,目录下会有两个文件。

在 GitHub 的 Setting 里面，找到 SSH keys，将 id_rsa.pub 中的内容复制到 key 里面，title可以随便填一个。

测试 SSH 连接是否成功建立

保存完以后，先在本地测试一下。
