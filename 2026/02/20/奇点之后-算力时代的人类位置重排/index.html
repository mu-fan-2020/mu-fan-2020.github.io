奇点之后：算力时代的人类位置重排

发表于2026-02-20|更新于2026-02-20|思考AI
|浏览量:

一、春节那天，你没看见的那条线

春节没回老家，一个人关在城市边缘的办公室里，窗外是亮得过分的商业区，远处高楼上挂着一个巨大灯牌：AGI Bar。

你当然知道那只是一块广告牌，但越看越觉得它像一根刻在天上的刻度尺——
文明曲线一路往上蹿，到这儿突然拐弯，开始接近垂直。

所谓“奇点”，对今天的人类，大概就是这种感觉：

  • 不是科幻片里那种“某一天AI觉醒、宣告统治人类”的戏剧性瞬间；
  • 而是在极长的一段时间里，技术像水位一样慢慢上涨，你每天都习惯性往下看一眼，觉得“也就那样”；
  • 某天你忽然发现，水已经涨到胸口，再往前一步就是游泳课了。

关键的那一刀，是底层前提被换掉了：

过去：智能是稀缺资源，好老师、好学校、好公司是稀缺智能的入口；
现在：智能第一次变成“可生产”的工业品，可以靠石油、煤、电力、阳光去“炼”。

训练一个顶级模型的过程，本质上就是：

  • 把能源和算力，
  • 转换成可以复用、可以复制、可以出租的“外接智力”。

以前你只能带着一颗脑袋去上班，最豪华的配置是“我 + 一个小团队”。
现在的设定变成：

  • 你可以有一整支不睡觉、不涨工资、不需要意义感的智能体队伍；
  • 它们可以在你睡觉的时候继续跑任务、翻资料、写代码、做实验。

一旦承认这一点，很多“老世界的常识”都得重算：

  • 学历是不是还那么重要？
  • 职业是不是还按“稳定、体面、有前途”来分？
  • 国家竞争力是不是还看“人口红利”和“受教育年限”？

奇点的含义不是“明天世界毁灭”，
而是：用“智能稀缺”建立起来的规则，开始普遍失效了。

二、200 美金，是人类最后的“智能平等期”

有个细节挺扎心的。

当年 ChatGPT Plus 出来的时候：

  • 20 美金 / 月，很多人嫌贵；
  • 更高配的 Pro、Max 套餐叠上去到 200 美金，就被骂成“智商税”。

从消费心理看，这没毛病；
但从“可用智能”的角度看，那段时间可能是人类历史上最平等的一段：

  • 你 200，我 200；
  • 用的是同一代模型、同一条推理链路；
  • 三线城市的自由职业者、刚毕业的大学生、硅谷基金合伙人，在“能调用的最高级 AI 智能”上，差距就是那 200 美金。

那会儿的现实是：

刚毕业的学生和上市公司 CEO，在“外接智能”维度上的差距，不超过一份订阅价。

现在这个窗口正在快速合上：

  • 模型分层：基础款、专业款、机构款、定制款，能力差距越来越大；
  • 价格分层：
    • 有人每个月在 AI 上烧几百块；
    • 有人在重度使用 Claude Code / GPT Code，一月 API 消耗轻松过千上万美金；
  • 使用方式分层：
    • 有人一天聊几句、让它写个周报；
    • 有人用几十上百个 Agent 做 7×24 小时的并行探索、策略迭代、监控预警。

未来完全可能出现这种对比：

  • A：一个人每月在 AI 上花 10 万美金，调度上千个 Agent 做并行搜索、决策、执行；
  • B：另一个人用免费额度，偶尔让 AI 帮自己润色一句话。

这不是“谁会不会用 ChatGPT”的问题，而是：

谁有资格、大规模地“燃烧 Token”。

智能一旦能被批量生产，就会立刻阶层化：

  • 顶级智能不再只是“你懂不懂用”的问题，而是你买不买得起；
  • 200 美金那个阶段，是穷人和富人在智能上的差距最小的时候，过了就不再回来。

三、算力即权力：新生产资料的马太效应

如果你拉一个冷血旁观者——比如一只“什么也不在乎”的 AI 龙虾 ——来看现在的局面，它可能会给出这样的结构图：

1. 算力是新的石油

链路大致是：

智能 → 模型 → Token → 算力 → 芯片 / 数据中心 → 电力 / 供应链

智能在数字世界指数型扩张：场景越多、用量越大、任务越复杂；
但算力的供给被物理约束：晶圆厂、光刻机、稀土、冷却、输电，全都不能指数涨。

所以发生的事是：

  • 需求指数型上涨，供给线性爬坡，
  • 算力成为这个时代最核心、而且高度集中的生产资料。

集中在哪里？你很清楚：

  • 高端芯片：几乎锁在少数几家代工厂和设计公司；
  • 云基础设施：集中在少数几家超级云厂商和大型互联网公司；
  • 顶级模型：掌握在极少数实验室和巨头手里。

每一次大规模推理、本质上都是在向这些算力地主交“地租”。

2. 正反馈飞轮

把经济学那句老话套过来：

“有算力者，必将获得更多算力。”

具体机制是：

  1. 算力越多 → 模型更强、效果更好；
  2. 模型更强 → 产品更好、用户更多、收入更高；
  3. 收入更高 → 能买到更多算力；
  4. 更多算力 → 进一步拉开差距。

这个飞轮一旦转起来，就是标准的马太效应。

3. 制衡机制在失效

现代民主制度背后有个不明说的前提：

资本需要劳动力。

因为需要人，工人有筹码：

  • 可以罢工；
  • 可以通过工会谈判；
  • 可以用选票影响政策。

而 Agent 正在动摇这个前提：

  • 即便只替代一部分岗位，“你不干，有 Agent 干”这句话本身就会压低所有劳动力的议价空间；
  • 劳动者筹码下降 → 政治影响力下降 → 有利于劳动者的政策更难推出；
  • 财富和算力向少数人集中 → 他们对制度、舆论、监管的影响力更大。

这是第二个飞轮，方向相反，却同样自我强化。

当你把这两部分叠在一起，就会得到那句有点刺耳的话：

未来很可能不是“资本 vs 劳动力”，而是“算力拥有者 vs 算力依附者”。

四、技术人在内部已经被“重写”了一次

如果你想感受这件事的“体感速度”，不如先从程序员的世界看起。

1. 从“协作工具”到“干活主体”

最近几年技术圈内部的经历，大致是这样一条路：

  • 2022：AI 写几行辅助代码，弥补了 Copilot 一类工具的空间；
  • 2023：可以写功能块，但需要你反复提示、改、重跑，像一个“勤奋但愚钝的实习生”；
  • 2024：开始能独立拉起子项目，但你要盯着，看它别乱搞；
  • 2025：顶级模型开始接管一个项目的大部分开发工作；
  • 2026：
    • 你用自然语言描述要做的产品：功能、UI、用户流程；
    • 它写出成千上万行代码，自己起服务；
    • 自己点页面、跑用例；
    • 自己看不爽的地方自己改，然后再测；
    • 满意了才把结果端到你面前：“来验收。”

重要的转折是：

你从“写代码的人”，变成了“描述目标 + 审核结果的人”。

2. “智能爆炸”的起点：AI 写 AI

更关键的一步，是 AI 不再只是帮你写业务代码，而是开始写下一代 AI 自己的代码。

  • 某些实验室已经公开写在技术文档里：
    新模型的训练系统、调试脚本、部署流程，大量是上一代模型写出来的；
  • 公司 CEO 出来访谈，轻描淡写地说：
    “我们公司大部分代码已经是 AI 写的了，人与 AI 的反馈循环在每个月加速。”

这就是“递归自我提升”的胚胎形态：

这一代 AI 帮你建好脚手架 →
下一代 AI 在更好的脚手架上生长 →
迭代间隔越来越短，幅度越来越大。

你过去习惯的“版本号 + changelog”的世界观，已经不足以描述这条曲线。

3. 6～12 个月：端到端接管大部分软件工程

有些人已经在公开场合给出非常具体的时间表：

  • 6～12 个月内，AI 有能力端到端接管大部分软件工程任务；
  • 不是只写一点代码，而是：
    • 接需求；
    • 选架构；
    • 写前后端；
    • 起环境；
    • 写测试；
    • CI/CD；
    • 甚至写发布用的说明文档。

与此同时，有人已经开始讲下一步——Prompt → 二进制：

“当前链路是：源代码 → 编译器 → 二进制 → 执行。
我觉得很快会变成：目标描述 → AI 直接生成优化好的二进制 → 执行。
中间那一步“写代码”，只是过渡形态。”

对于工程师来说，这意味着：

  • 你原来视作“核心竞争力”的那部分工作，
    正在迅速变成机器内部的一个中间过程；
  • 你如果还把“我会某种语言”当成护城河，
    这个护城河的水位正在抽干。

五、工作与教育：边际成本归零之后

当大量认知劳动的边际成本逼近于零时，一些很不舒服的结论会自然浮现出来。

1. 产出低于电费的那一刻

想象这样的对比：

  • 一个刚毕业的大学生写一份行业报告，需要一周，成本是：
    • 时间 × 一周；
    • 加上房租、通勤、办公场地、管理成本……
  • 一个 Agent 写同样一份报告，需要几分钟：
    • 随手连几条 API；
    • 电费不到一块钱。

如果两份报告的质量差距不大，甚至 Agent 更好，那……

这个毕业生一周的劳动，对世界的经济价值确实可能低于电费。

这不是愤青式夸张，而是当“智能边际生产成本趋近于零”之后，必然出现的比较尺度。

再把这条逻辑链拉长一点：

  • Karpathy 说，现在大部分 Agent 的输出都是“slop”：看上去像那么回事，仔细一看全是问题；
  • 但已有数据表明，Agent 实际可用能力大约每 7 个月翻一倍，最近甚至有缩到 4 个月的趋势。

“slop”会停留多久？
没人能给你保证。

2. 教育窗口期被压缩到离谱

在“智能稀缺”的时代，教育的逻辑很简单：

  • 用十几二十年把一套知识灌进一个人脑袋里；
  • 社会为这套知识付工资，知识兑现为职业。

现在的前提是：

  • 模型可以在几周训练里吃掉全人类几十年的文本、代码、论文、判例、财报；
  • 你大学四年学的那点东西，它训练时可能四分钟就扫完了。

这带来一个很残忍的现实：

传统意义上的“学一门专业，吃一辈子饭”的时代，正在快速消失。

这并不意味着教育不重要，而是：

  • 教育的价值重心，得从“教知识”，
    转到“重塑思维方式 + 训练与智能协作的能力 + 让你看清自己到底想要什么”。

如果还按旧剧本——
“考好大学 → 找稳定专业 → 等退休”，
那你整套路径极有可能在你毕业前就开始过期。

六、奇点之后，真正追不上的到底是什么？

在各种“窗口正在关闭”“你再不上车就废了”的话术里，有必要拆一下：到底啥东西真的是追不上的？

1. 工具差距：半年 vs 半小时

假设有人半年前就开始用比较成熟的 Agent 系统，
你是半年前放弃，现在才入场。

  • 从“会不会用工具”这个维度看，差距就是半年；
  • 但工具本身在不断压缩这个差距 ——
    从 Second-Me 时代要折腾几天部署，到现在 OpenClaw 半小时起盘，一个人都能搞出来 AI 搭子。

工具差距是实在的，但可以被压缩。

2. 认知差距：高度可迁移

先行者这半年里：

  • 用 Agent 把自己的工作拆了一轮；
  • 踩了大量坑，试过决策、监控、内容生产、自动化；
  • 偶尔写篇长文，讲讲经验和踩坑。

这些东西不是只在他脑子里，会：

  • 变成文章、播客、视频、课程；
  • 被你反复阅读、模仿、改造成自己的方法论。

认知差距是存在的，但可以通过学习和实践迁移。

3. 真正难追的是“社会资本与位置”

最难追的部分反而是被经常忽略的：

  • 提前积累起来的流量和受众；
  • 行业里的地位、话语权；
  • 在正确时间上牌桌、占到关键坑位；
  • 提前押准方向拿到的资本、资源、人脉。

这些东西具有极强的正反馈：

  • 有一点势能 → 更容易拿到资源 → 更容易做大项目 → 得到更多势能；
  • 后来者想复制这条路径，往往要付出的成本是指数级的。

现在很多“奇点焦虑”的文案，其实干的是：

拿社会资本的先发优势，包装成“认知上的绝对压制”。

拆开看之后，比较诚实的说法应该是：

  • 你确实会在话语权、资源、位次上被拉开差距；
  • 但这不等于“你注定变成认知残障”；
  • 你能做的是：
    • 在自己的约束下，把工具与认知拉到“足够好”；
    • 把有限的算力和时间，砸在对你而言最有杠杆的地方。

七、人和机器：价值不等于产出

还有一个更底层但被经常偷换的前提：

“人的价值 = 人的产出。”

只要把价值和“生产力”绑死，你在 AI 面前永远没法不焦虑，因为在产出这个维度，人类注定打不过机器。

但你真要承认这个等号吗？

  • 吃饭、散步、发呆、看夕阳；
  • 和朋友聊天、陪孩子长大；
  • 发一条只自己觉得好笑的动态；
  • 夜里走在空无一人的桥上，突然觉得这城市其实也没那么讨厌。

这些东西价值几何？用什么算？算在谁头上？

当你开始不耐烦地问“这有什么用”的时候，
其实已经在默认：人只是生产力机器，人活着就是为了“提高效率”。

在一个“执行成本趋近于零”的世界里，
真正稀缺的东西，反而变成了：

  • 欲望本身（你到底想要什么）；
  • 审美、趣味、偏好；
  • 愿意为之浪费时间、甚至付出代价的那点东西。

AI 可以无限接单，解决所有“明确提出的问题”。
但提出问题的人是谁，这个权力，它代替不了。

八、大事正在发生，但大多数人还在原地生活

现在有一个非常诡异的割裂：

一边，是搞模型的人说：

  • “我 90% 确信，2035 年前会出现‘数据中心里的天才国度’，甚至一两年内就能看到影子”；
  • “模型已经从聪明高中生进化到可以完成博士级工作”；
  • “说十年内达不到 AGI，我觉得才是疯狂”。

另外一边，你打开朋友圈 / 抖音：

  • 油价、房价、考公、股市、鸡娃；
  • 对 AI 的理解停留在“写工作总结、写周报挺好用”。

很多搞 AI 的人承认：
自己对外用了两套话术。

  • 给圈内人：
    • 讨论参数规模、训练技巧、对齐、安全、奇点时间表；
    • 真正会承认“我们自己都被吓到了”；
  • 给圈外人：
    • 平静、礼貌、“看长远会很好”“不用太焦虑”；
    • 避免让人觉得“这货脑子坏掉了”。

这就形成 Matt 那个比喻：

现在像 2020 年 2 月：
少数人已经看到墙角有一团火，
大多数人还在排队等位、准备出国旅游。

差别在于：

  • 那次是病毒，你能看到“封城”“停课”“戴口罩”；
  • 这次是智能体，它在云里，对你“悄无声息地生效” ——
    直到有一天，你发现自己和整个系统之间的权力关系已经改变。

九、在“天才国度”的边缘，个人到底能做什么？

把情绪撇开，给自己列一个更务实的清单。

1. 接受现实：它已经近到能伤到你

如果你还在“等它成熟再说”的心态，那基本已经是在放弃这局。

你不一定要去卷底层模型训练，
但至少可以做这几件事：

  • 搭一套自己的 AI 工作环境，而不是只在浏览器里偶尔玩玩网页版；
  • 把你日常工作拆开，看哪些环节可以交给 Agent 做：
    • 信息收集、整理、总结；
    • 简单决策前的分析和对比；
    • 重复性高、规则稳定的流程；
  • 养成一个习惯：
    • 任何重复超过三次的认知劳动，先问一句“能不能 Agent 接手？”

2. 把自己从“算力贫民”挪到“算力中产”

用你的配置来说就是：

  • 有一套像 OpenClaw 这样的本地 Agent OS，而不是只靠云上的聊天框；
  • 有几条固定的“智能流水线”：
    • 读文章→自动抓→本地存档→生成笔记草稿；
    • 项目管理→状态汇总→风险预警；
    • 代码 / 配置变更→自动 review→生成 changelog。

目标不是“追上大厂”，
而是在自己可控的范围内，尽量多掌握一些自用算力 + 自有工具链。

3. 想清楚你要扮演什么角色

把那句有点俗的话再说一遍：

未来活得比较舒服的，大概还是那几种人：

  • 能熟练驱动大模型和 Agent 的技术 + 业务复合型；
  • 在某个垂直领域已经站到前排，并用 AI 放大自己的人；
  • 有资本、又能看懂局势，把算力配置在关键点上的人。

你不一定要成为其中任何一类的头部，
但要避免把自己锁定在：

  • 完全由别人搭好的智能系统来决定你看到什么、做什么、赚多少钱、怎么花。

你可以不当“掌舵者”，
但尽量别做“全程闭眼坐在船舱里的那个人”。

4. 把“每天一小时”当成最小诚意

这句话可以写死：

每天拿出一小时，只做一件事：实验 AI。

不是刷文章，不是看别人用，而是自己上手：

  • 把今天最花时间的一项工作，
    尝试交给 AI / Agent 做一遍；
  • 不断换不同的问法、约束、工具组合，
    看看你能把这件事外包到什么程度。

坚持三个月，你对这波变革的体感，会和周围 99% 的人不一样。

十、结语：规则变了，轮到你重新选立场

把你刷到的那些句子串在一起：

  • “我们，已经迈过奇点。”
  • “算力即权力。”
  • “程序员只剩 6 个月。”
  • “数据中心里的天才国度快来了。”

听多了确实容易让人要么瘫掉，要么上头。

但把所有细节合在一起看，其实更像是在提醒你：

  1. 游戏规则真的在变，而且变得比你习惯的节奏快。
    智能从稀缺资源变成可生产的基础设施，
    很多旧秩序会自然解体。

  2. 你仍然有一点点主动权。
    工具和认知的差距，可以通过学习和实践压缩；
    真正难追的是社会资本与平台位置，而不是智商。

  3. 你的立场，不是自动决定的。
    你可以选择把自己当作系统中的一个可替代节点，
    也可以选择至少掌握一部分算力和 Agent，
    在自己的世界里多争取一点话语权。

奇点不会给你发开服公告。
现在它已经安静地过去了，
剩下的问题，不再是“会不会来”，而是：

在这个新游戏里，你打算站在哪一边？
