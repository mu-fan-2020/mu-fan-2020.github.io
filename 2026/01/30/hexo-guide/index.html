这是最关键的一步，我们将博客发布到互联网上。

创建 GitHub 仓库

  1. 登录 GitHub。
  2. 创建一个新仓库，仓库名必须严格符合格式：<你的用户名>.github.io。
    • 例如：如果你的用户名是 john, 仓库名必须是 john.github.io。

⚠️ 安全提示：关于 Token

GitHub 不再支持密码验证，你需要使用 Personal Access Token。

  1. 进入 GitHub Settings -> Developer settings -> Personal access tokens。
  2. 生成一个新 Token (Classic)，勾选 repo 权限。
  3. 重要：部署时如果提示输入密码，请输入这个 Token，而不是你的 GitHub 登录密码。
