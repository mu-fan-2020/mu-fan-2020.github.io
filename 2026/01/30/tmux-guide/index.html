什么是 Tmux

Tmux (Terminal Multiplexer) 是一个终端复用工具，主要功能：

核心优势：

  • 会话持久化 - SSH 断开后程序继续运行
  • 多窗口管理 - 一个终端管理多个会话
  • 分屏操作 - 同时查看多个任务
  • 团队协作 - 多人共享同一会话

适用场景：

  • 远程服务器管理
  • 长时间运行任务
  • 多任务并行操作
  • 结对编程

基础概念

Tmux 采用三层结构：

Session（会话）

  • 最外层容器
  • 一个 Session 包含多个 Window
  • 断开连接后 Session 依然运行

Window（窗口）

  • 类似浏览器标签页
  • 一个 Window 包含多个 Pane
  • 底部状态栏显示所有 Window

Pane（面板）

  • 最小单位
  • 在一个 Window 内分屏显示
  • 每个 Pane 是独立的终端

所有快捷键都以 Ctrl+b 开头（称为 Prefix），按完 Prefix 再按功能键。

窗口管理

快捷键 功能

Ctrl+b , 重命名当前窗口

最佳实践

命名规范

  • 会话：项目名或任务类型（dev, deploy, monitor）
  • 窗口：功能描述（editor, server, logs）

资源管理

  • 定期清理不用的会话：tmux kill-session -t name
  • 使用 tmux ls 查看活动会话
  • 避免创建过多嵌套的 tmux

安全建议

  • 不要在共享服务器上留敏感信息
  • 及时断开不用的会话
  • 注意多人协作时的隐私
