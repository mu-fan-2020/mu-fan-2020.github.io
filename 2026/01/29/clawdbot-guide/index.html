问题 2: ARM64 架构下 better-sqlite3 编译失败

现象:

  • 使用 better-sqlite3 的项目无法运行
  • 报错：Could not locate the bindings file

总结

关键要点

  1. 使用 fnm 管理 Node.js 版本 - 避免系统包管理器安装的版本过旧，推荐使用 v22 LTS 版本

  2. 完全清理后重新安装 - 遇到配置问题时，完全清理是最可靠的解决方案，记得备份重要数据

  3. API 配置使用配置文件方式 - 不要依赖环境变量，注意 baseUrl 的 /v1 后缀

  4. 定期查看日志 - 日志是排查问题的最佳工具，使用 journalctl 或 clawdbot logs

  5. ARM64 架构注意事项 - 某些 npm 包可能需要编译，优先选择纯 JavaScript 实现的替代方案
