Claude 的上下文优势

  • Opus 4.7 支持 1M tokens（约 75 万字）
  • 但是！前 20% 和后 20% 的注意力最强
  • 中间部分容易”丢失”（Lost in the Middle 现象）

优化策略

  1. 关键信息放头尾：把约束、目标放在开头，把当前任务放在结尾
  2. 结构化分块：用 ## 标题 分块，AI 更容易索引
  3. 主动压缩：长对话用 /compact（Claude Code）
  4. 外置记忆：用 memory/ 目录、Memento MCP、向量数据库

Claude Code 专属技巧

  • /init — 让 Claude 阅读你的项目并生成 CLAUDE.md
  • /compact — 手动压缩对话上下文
  • /clear — 清空当前会话
  • # 记录 — 把当前内容存进 memory
  • !命令 — 直接执行 shell 命令并把输出注入对话

GPT 专属技巧

  • Function Calling：让 GPT 主动调用你的函数
  • JSON Mode：强制输出合法 JSON
  • Structured Output：基于 Schema 严格约束输出
  • Vision：直接传图片让 GPT 分析
